# Python Exercises

The scripts written on days 3–4 of the internship, working through an introductory Python course.
Each file covers a single concept and runs directly: `python file_name.py`.

> 🇷🇴 Documentul în limba română: [README.ro.md](README.ro.md)

| Topic | Files |
|---|---|
| Variables, types, conversions | `variabile.py`, `type_conversion.py`, `type_conversion2.py`, `input.py` |
| Strings | `strings.py`, `string_methods.py`, `formatted_strings.py` |
| Operators | `arithmeticop.py`, `logical_op.py` |
| Conditionals | `if_statements.py`, `ex_if.py` |
| Loops | `for_loops.py`, `while_loops.py` |
| Data structures | `lists.py`, `2Dlists.py`, `tuples.py`, `dictionaries.py` |
| Functions | `functions.py`, `keyword_arguments.py`, `return_statement.py`, `reusable_function.py` |
| Object-oriented programming | `classes.py`, `constructors.py`, `inheritance.py` |
| Modules and packages | `modules.py`, `utils.py`, `path1.py`, `app.py` |
| Exceptions | `exceptions.py` |
| Mini-applications | `car_game.py`, `emoji_converter.py`, `weight_converter.py`, `converters.py`, `random_values.py` |

`car_game.py` (a small console game with `start` / `stop` / `help` commands) and
`emoji_converter.py` are the recap exercises — they put loops, dictionaries and functions together.
