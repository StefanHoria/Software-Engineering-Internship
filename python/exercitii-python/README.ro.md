# Exerciții Python

> 🇬🇧 English version: [README.md](README.md)
Scripturile scrise în zilele 3–4 de practică, parcurgând un curs introductiv de Python.
Fiecare fișier tratează un singur concept și se rulează direct: `python nume_fisier.py`.

| Temă | Fișiere |
|---|---|
| Variabile, tipuri, conversii | `variabile.py`, `type_conversion.py`, `type_conversion2.py`, `input.py` |
| Șiruri de caractere | `strings.py`, `string_methods.py`, `formatted_strings.py` |
| Operatori | `arithmeticop.py`, `logical_op.py` |
| Condiții | `if_statements.py`, `ex_if.py` |
| Bucle | `for_loops.py`, `while_loops.py` |
| Structuri de date | `lists.py`, `2Dlists.py`, `tuples.py`, `dictionaries.py` |
| Funcții | `functions.py`, `keyword_arguments.py`, `return_statement.py`, `reusable_function.py` |
| Programare orientată pe obiecte | `classes.py`, `constructors.py`, `inheritance.py` |
| Module și pachete | `modules.py`, `utils.py`, `path1.py`, `app.py` |
| Excepții | `exceptions.py` |
| Mini-aplicații | `car_game.py`, `emoji_converter.py`, `weight_converter.py`, `converters.py`, `random_values.py` |

`car_game.py` (un mic joc în consolă cu comenzi `start` / `stop` / `help`) și
`emoji_converter.py` sunt exercițiile recapitulative — pun cap la cap bucle, dicționare
și funcții.
